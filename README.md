# 壁画修复注胶 · 长针扫掠安全校核

壁画修复室为细裂隙注胶前，校核长针从起始朝向旋转到注入朝向的整个扫掠过程是否会擦到脆弱颜料区。纯前端实现，所有几何计算仅在本机浏览器内完成，不上传任何数据。

## 功能

- 录入或在画布中拖动 **2–5 根针**：支点、针长、起始角、终止角、顺/逆时针方向。
- 录入或拖动 **1–6 个颜料保护圆**：圆心、半径。
- 录入校验：同一根针的起止角必须不同（含相差 360° 的等价情形）；保护圆不得覆盖任何支点。
- 点击「校核」后，把每根针身连续扫过的区域作为**带方向的圆扇形**精确判断（不是只检查两个停靠角度）：
  - 保护圆与扫掠区域**相交或相切均判为不安全**；
  - 每根针显示**最小净距**（安全时）或**首次触及角度**（风险时）；
  - 出现风险时，按**针的录入顺序**、再按**该针旋转方向上的最早触及位置**给出首项冲突及涉及的保护圆。
- 可启用 **分步注胶**，拖动排定 2–5 根针的执行顺序并录入**最小针间净距**：
  - 每一步仅执行针从起始角转至注入角：**已完成针停在注入角，未执行针保持起始角**；
  - 除原有颜料圆风险外，活动针身与任一停驻针身的距离必须**始终严格大于**最小针间净距——**端点接触或等于限值均不得放行**；
  - 对每一步**连续**求活动针扫掠时与停驻线段的首次越界角度（不是只比较步骤起止姿态或采样角度）；
  - 首项风险按**执行步骤**、再按**停驻针录入顺序**稳定返回；安全时列出每步最小针间净距及对应针号；
  - 修复师可依据最早越界的执行步骤和停驻针号调整注胶顺序后重新校核；
  - 任一针参数、执行顺序或针间净距修改都会作废旧校核结果。
- 未启用分步注胶时，仍按原有保护圆校核结论、净距与首项冲突方式工作。

## 坐标约定

画布左下角为原点，y 轴向上；角度以正东为 0°、逆时针为正（单位：度）。

## 运行

```bash
# 构建并启动静态站点（默认宿主机端口 8080）
docker compose up -d web

# 自定义宿主机端口
WEB_PORT=9000 docker compose up -d web

# 访问
open http://localhost:9000
```

web 容器内置健康检查（`wget` 请求首页），`docker compose ps` 可查看健康状态。

## 一次性校验（代码测试 + 构建 + 扫掠模块烟测）

```bash
# 方式一：退出码即校验结果
docker compose run --rm verify

# 方式二
docker compose up --exit-code-from verify verify
```

`verify` 服务依次执行：

1. `tests/sweep.test.js` — 扫掠几何模块单元测试；
2. `scripts/build.js` — 语法检查、资源引用核对并装配 `dist/`；
3. `scripts/smoke.js` — 注胶扫掠模块烟测（模拟修复室录入，验证首项冲突与安全放行；含分步注胶的首项风险定位、调序放行与等于限值判越界）。

任一步骤失败即以非零码退出，全部通过以 0 退出。

## 本机开发（无需 Docker）

```bash
node scripts/verify.js   # 或分开执行 npm test / npm run build / npm run smoke
```

直接用任意静态服务器（如 `python3 -m http.server`）托管仓库根目录即可打开页面。

## 几何方法

针身扫掠区域 = 以支点为圆心、针长为半径、从起始角沿指定方向转到终止角的圆扇形。

- **最小净距** = 圆心到扇形区域的最短距离 − 半径。圆心角向落在扇形角域内时，距离为 `max(0, d − 针长)`；否则为到两条径向边界线段的最短距离。净距 ≤ 0（相交或相切）即不安全。
- **首次触及角度**：针身触及某圆的角度集合是以圆心方位角 φ 为中心的连续区间 `[φ−γ, φ+γ]`，其中切点在针长内时 `γ = asin(r/d)`（切线边界），否则 `γ = acos((d²+L²−r²)/(2dL))`（针尖掠圆边界）。沿旋转方向找到首个落入该区间的角度即可。

分步注胶的针间净距（活动针身线段 vs 停驻针身线段）：

- **越界角区间**：净距 ≤ 限值 c ⟺ 针身与「停驻线段膨胀 c 的胶囊体 ∩ 针尖圆盘」相交。该交集为凸集，从支点看命中方向构成**单个连续角区间**。枚举全部候选边界角（端点圆盘切线、针尖圆与端点圆/两侧偏移线的交点），对候选角及弧段中点逐一做精确线段间距判定，拼出越界区间，再沿旋转方向求首次进入的角度——全程连续精确，非采样。
- **扫掠最小针间净距** = min（支点到停驻线段、停驻线段两端点到扫掠扇形、针尖圆弧到停驻线段、相交时为 0），各分量均有闭式候选角精确求值。
- 安全条件：整个扫掠过程中净距**严格大于**限值（等于限值即判越界）。
